# Trabalho 3 - Modelagem (Engenharia de Software)

Este repositório contém os artefatos de modelagem aprofundada de 3 fatias verticais selecionadas do sistema de Frotas e Viagens, desenvolvidos para a disciplina de Engenharia de Software.

A filosofia adotada foi **profundidade sobre largura**, detalhando estruturalmente e comportamentalmente os fluxos mais críticos do sistema.

## 📚 Estrutura da Documentação

A documentação foi dividida em arquivos Markdown modulares, localizados na pasta `/docs`:

1. [00. Seleção de Escopo e Justificativa](docs/00-selecao-de-escopo.md)
2. [01. Diagrama de Classes](docs/01-diagrama-de-classes.md)
3. [02. Modelo Entidade-Relacionamento (MER)](docs/02-mer.md)
4. [03.1 Comportamental - Fatia 1 (Sequência)](docs/03-comportamental-fatia1.md)
5. [03.2 Comportamental - Fatia 2 (Estados)](docs/03-comportamental-fatia2.md)
6. [03.3 Comportamental - Fatia 3 (Sequência)](docs/03-comportamental-fatia3.md)
7. [04. Casos de Teste IEEE](docs/04-casos-de-teste.md)
8. [05. Matriz de Rastreabilidade](docs/05-rastreabilidade.md)

## 🛠️ Ferramentas Utilizadas
* **Markdown (GFM):** Estruturação de toda a documentação.
* **Mermaid.js:** Geração dos diagramas (Classes, MER, Sequência e Estados) de forma nativa e versionável.
